# 高校共享自习空间导览平台 · ditu-yuanli

基于真实校园点位手绘地图的**纯前端**导览演示：教学楼 / 教室占用状态实时可视，一键找到身边最近的空闲自习室。

## 在线访问（GitHub Pages）

部署后常驻线上，与本地是否开机无关，手机 / 电脑均可访问：

```
https://2708053544.github.io/ditu-yuanli/
```

> 若访问 404，请在仓库 **Settings → Pages** 中把 Source 设为 `main` 分支 `/ (root)` 并 Save。

## 功能

- **多校选择**：天津仁爱学院 / 天津大学 / 南开大学 / 清华 / 北大 / 复旦 / 上交 / 浙大 / 南大 / 武大 / 中山 / 川大 / 哈工大 / 西安交大 等 14 所高校，各校为独立模拟数据
- **演示登录**：任意用户名 + 3 位以上密码即可登录
- **教室占用状态**：空闲（可直接自习）/ 即将下课（≤15 分钟）/ 上课占用（请勿打扰）
- **手绘校园地图**：楼宇、食堂、快递站、卫生间、校门等点位标注
- **步行导航**：我的位置 / 校门 → 任意终点
- **查找教室**：按楼栋查看各层教室状态
- **响应式布局**：自动适配手机与电脑

## 技术说明

- 纯前端单文件 `index.html`，CSS / JS / 地图 SVG 全部内联，无任何外部依赖，可离线运行
- 模拟样例数据，用于校园创意赛作品展示，非真实占用数据

## 本地运行

直接用浏览器打开 `index.html` 即可，无需服务器。

## 部署到 GitHub Pages（已配置）

```bash
git add .
git commit -m "deploy: 高校共享自习空间导览平台（自包含响应式静态站点）"
git push origin main
```

然后在仓库 **Settings → Pages** 选择 `main` 分支 `/ root` 启用即可。
